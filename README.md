# Prince Kumar - Portfolio Website

A personal portfolio website showcasing my **skills, projects, certifications, and education**.  
Built with **HTML, CSS, and JavaScript**, this portfolio highlights my journey as an aspiring **AI & Data Engineer**.

---

## 🚀 Features
- Hero Section: Introduction, career goals, and quick links (GitHub, Resume, Email).
- Projects Section: Featured projects with descriptions, technologies used, and code links.
- Skills Section: Categorized skills (Languages, Frontend, Backend).
- Education Section: Academic background with school and university details.
- Certifications Section: Professional certifications (Microsoft AZ-900, DP-600, DP-601, TCS iON AI & Cybersecurity Awareness).
- Contact Section: Easy access to Email, GitHub, LinkedIn, and Resume.

---

## 🛠️ Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Styling: Custom CSS with responsive design
- Icons: Font Awesome
- Hosting: GitHub Pages / Netlify / Vercel
